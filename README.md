# Deck Mentor

Плагин для [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader): во время игры на Steam Deck спрашиваешь Claude, что делать дальше. Работает **по подписке Claude** (Pro/Max) через официальный Claude Code, по желанию можно включить API-ключ.

## Что умеет

- **Быстрые кнопки в меню «…»**: «📷 Что мне делать?», «📷 Как пройти это?», «📷 Объясни экран», «🧭 Что я пропустил?». Меню на секунду закрывается, плагин делает скриншот игры без оверлея, и ответ печатается прямо в панели.
- **Свой вопрос** с экранной клавиатуры или голосом (кнопка «🎤 Сказать»), со скриншотом или без.
- **Горячая клавиша** (по умолчанию зажать **L4 + R4**). Claude смотрит на экран и отвечает уведомлением, игру ставить на паузу не нужно.
- **Голосовой вопрос** (включается в настройках): зажмите **L5 + R5**, скажите вопрос и отпустите. Речь распознаётся прямо на Деке и только пока кнопки зажаты.
- **Озвучка ответов** (по желанию): ответы на горячие клавиши читаются вслух, у любого ответа есть кнопка «🔊 Прочитать».
- **Спойлеры под шторкой**. В режиме намёков сначала приходит подсказка, а полное решение спрятано за кнопкой «🙈 Показать решение».
- **Глубокий разбор**. Плагин копирует сохранения игры, Claude разбирает их своими скриптами, смотрит файлы игры и интернет и пишет гайд по твоему прохождению: где ты, что делать дальше, что пропустил, какой билд собрать. Гайд сохраняется, и быстрые вопросы дальше его учитывают.
- **Не только Steam**. Сохранения ищутся в префиксах Proton, Steam Cloud, Heroic, Lutris, Bottles, в папках нативных Linux-игр, эмуляторов (EmuDeck) и неофициальных портов вроде Ship of Harkinian, 2Ship2Harkinian и Zelda64Recompiled. Плагин смотрит, какую программу на самом деле запустил Steam, и берёт сейвы из её папки, а для остального ищет по названию ярлыка. Если не нашлось ничего, Claude получает недавно изменённые файлы сохранений и сам разбирается, какие из них от этой игры.
- **Достижения и время в игре**. Если Steam их знает, Claude по ним понимает, как далеко ты прошёл. Для игр без достижений всё работает и без них.
- **Чтение на весь экран** для длинных ответов и гайдов: листается стиком или крестовиной.
- **Лимит подписки** в панели: сколько потрачено за 5 часов и за неделю и когда сброс.
- **Обновления из панели**: плагин раз в 12 часов проверяет новые версии, а установку подтверждает сам Decky.
- **Поиск в интернете** по вики и гайдам, чтобы Claude не выдумывал названия и места.
- **Отдельная история для каждой игры** и заметка «где я сейчас».
- **Автоочистка диска** (подробности ниже).

## Установка

1. **Decky Loader** должен быть установлен.
2. **Claude Code** ставится один раз в режиме рабочего стола (Steam → Питание → Переключиться на рабочий стол). Откройте Konsole и выполните:
   ```bash
   curl -fsSL https://claude.ai/install.sh | bash
   ~/.local/bin/claude
   ```
   В Claude Code введите `/login` и войдите в аккаунт с подпиской. Вход делает сам Claude Code в браузере, плагин твои данные не видит и не хранит.
3. **Плагин**: в Decky → Настройки включите «Режим разработчика», затем в «Установить плагин по URL» вставьте
   ```
   https://github.com/FPSarmin/deck-mentor/releases/latest/download/deck-mentor.zip
   ```
   Можно и скачать этот zip и выбрать «Установить плагин из ZIP».
4. Вернитесь в игровой режим, откройте «…» → Decky → **Deck Mentor**. Если что-то не настроено, плагин покажет, что сделать.

## Как пользоваться

- В игре нажмите «…», откройте Deck Mentor и выберите кнопку или задайте свой вопрос.
- Либо зажмите **L4 + R4**: через несколько секунд придёт уведомление с подсказкой, а полный ответ будет в панели.
- Голосом: включите «🎤 Голосовой вопрос» в настройках (скачается модель ~57 МБ), потом зажмите **L5 + R5**, скажите вопрос и отпустите. В панели то же самое делает кнопка «🎤 Сказать»: первое нажатие начинает запись, второе распознаёт речь в поле вопроса.
- Для подробного плана запустите **🔬 Разобрать сохранения**. Это занимает 3–10 минут, играть при этом можно.

### Голос и нагрузка на Деку

Распознавание и озвучка выключены по умолчанию. Когда они выключены, плагин ничего не скачивает и не держит в памяти. Когда включены, в фоне тоже ничего не работает: микрофон открыт только пока зажаты кнопки, а процессор занят 1–3 секунды на распознавание или озвучку одного ответа. Модели скачиваются при включении (распознавание ~57 МБ, озвучка ~85 МБ) и удаляются кнопкой «Удалить голосовые модели».

## Диск и временные файлы

Переписка по умолчанию хранится всегда: и история вопросов и ответов в плагине, и переписка самого Claude Code в `~/.claude/projects/…`. Если захотите ограничить срок, выберите в настройках «Хранить переписку: 7 / 30 / 90 дн.».

Временные файлы плагин убирает сам:

- скриншоты он держит только в памяти и не пишет их на диск отдельно;
- копии сохранений и черновые скрипты удаляет сразу после глубокого разбора, а сохраняет только `guide.md`;
- резервные копии файлов, которые Claude Code делает для своих сессий (`~/.claude/file-history`), тоже удаляет;
- проверяет всё это при запуске и потом каждые 6 часов. Кнопка «Очистить временные файлы» запускает проверку сразу.

«Новый разговор» начинает для Claude чистый контекст, но история в плагине при этом остаётся. Сам плагин тоже начинает новый разговор после 6 скриншотов или 16 вопросов, чтобы ответы не замедлялись.

Плагин удаляет только свои файлы. Другие проекты Claude Code он не трогает.

## Безопасность

- При глубоком разборе Claude работает с **копией** сохранений в папке плагина, оригиналы ему не передаются.
- Писать файлы Claude может только в папке этой игры внутри плагина, а из команд разрешены только `python3` и команды для чтения. Остальное блокирует сам Claude Code.
- Плагин запускает неизменённый официальный `claude` и не читает и не хранит данные входа. Пользоваться подпиской так можно только на своём устройстве и в своём аккаунте, раздавать доступ другим нельзя ([условия](https://code.claude.com/docs/en/legal-and-compliance)).

## Разработка

```bash
pnpm install
pnpm run typecheck
python3 tests/test_offline.py            # PNG, скриншот (videotestsrc), кнопки, очистка, сейвы, промпты
python3 tests/test_voice.py              # нужен bin/whisper-cli: скачивание моделей, озвучка и распознавание
DECK_MENTOR_GST_SOURCE="videotestsrc pattern=smpte" python3 tests/test_e2e.py [deep]   # настоящий вызов claude
pnpm run package                          # out/deck-mentor.zip
```

Код устроен так:

- `main.py` содержит методы, которые вызывает панель.
- В `py_modules/deck_mentor/` лежат модули:
  - `claude_cli.py`: запуск `claude -p` с потоковым JSON;
  - `capture.py`: скриншот через PipeWire и gamescope;
  - `hotkey.py`: чтение кнопок из `/dev/hidraw`, только чтение;
  - `games.py`: поиск папки игры и сохранений (Steam, Heroic, Lutris, Bottles, нативные игры, эмуляторы);
  - `running.py`: какие процессы запустил Steam для текущей игры (только чтение `/proc`);
  - `voice.py` и `downloads.py`: голосовой ввод (whisper.cpp) и озвучка (piper), скачивание моделей;
  - `cleanup.py`: очистка;
  - `prompts.py`: тексты запросов к Claude.
- В `src/` лежит интерфейс на React.
- `whisper-cli` собирается в GitHub Actions (`.github/workflows/build.yml`) и кладётся в zip как `bin/whisper-cli`.
